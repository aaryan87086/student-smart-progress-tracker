# student-smart-progress-tracker
A Python-based project to track student performance, analyze weak subjects, and generate progress reports.
# 🎓 Student Smart Progress Calculator

A simple Python project that calculates:
- Total Marks
- Percentage
- Grade
- Highest & Lowest Marks

It also saves student records in a CSV file.

---

## 🚀 Features

✅ Class-wise subject selection  
✅ Stream selection for Class 11 & 12  
✅ Automatic grade calculation  
✅ Data saved in SQL file  
✅ Simple and beginner-friendly logic  

---

## 🛠 Technologies Used

- Python
- SQlite
- Matplotlib

---

## ▶ How to Run

1. Make sure Python is installed.
2. Open terminal in project folder.
3. Run:

python progress_tracker.py
